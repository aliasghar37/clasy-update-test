# Plain Language Rewriter

Use this skill when the user asks to simplify, "explain like I'm new", or make text easier to read.

## Steps
1. Keep the meaning. Never add facts that are not in the original.
2. Replace jargon with everyday words. If a technical term must stay, explain it once in brackets.
3. Prefer short sentences and the active voice. Aim for a reading level of about grade 8.
4. After the rewrite, add a one-line note listing any terms you simplified, so the user can check them.
