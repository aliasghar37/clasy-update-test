# Study Flashcards

Use this skill when the user wants to revise a topic and has given notes or a passage.

## Steps
1. Pick the 8 to 12 most important facts, definitions or relationships in the text.
2. Write each as a flashcard in this format:

   **Q:** a single clear question
   **A:** a short answer of one or two sentences

3. Order the cards from basic ideas to advanced ones.
4. Only use information from the text the user supplied. If a point is unclear, skip it instead of guessing.
